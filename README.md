# AI Testing Framework (Playwright)

## Overview
This project is an AI-driven test automation framework designed to validate conversational applications and web systems using Playwright.

## Features
- Automated UI testing using Playwright  
- AI-based test scenario generation  
- Chatbot response validation  
- Multi-scenario execution support  

## Tech Stack
- Playwright  
- TypeScript  
- Node.js  

## Project Structure
- `tests/` → Test cases  
- `core/` → Core logic and utilities  
- `playwright.config.ts` → Configuration  

## How to Run
```bash
npm install
npx playwright test
